# 国家下钻城市点亮地图设计规格

## 背景与纠偏

当前版本以“全球城市点搜索 + 单城市边界按需查询”为核心，不能满足用户直接浏览并点击行政区的目标。本次重构将主流程改为：世界地图点击国家，进入国家地图，展示该国对应行政层级的全部可选边界，点击区域立即点亮。

当前线上版本在新版本完整验收前保持不变，不进行原地半成品替换。

## 产品模型

### 世界地图

- 初始页显示二维世界国家底图和少量国名。
- 国家区域是导航入口，不是到访记录本身。
- 点击国家进入国家地图。
- 含到访城市的国家使用浅珊瑚色提示，并显示已点亮区域数量。
- 世界层不显示城市光点。
- 搜索国家时进入国家；搜索城市时加载所属国家并聚焦目标行政区。

### 国家地图

- 进入国家后自动适配国家范围。
- 展示该国最接近城市治理范围、且边界完整的行政层级。
- 中国采用地级行政区，日本采用市町村，美国采用县、县级市及独立市；其他国家由显式映射表选择对应层级。
- 所有区域显示浅色边界；到访区域统一填充珊瑚橙。
- 点击未点亮区域立即创建到访记录并打开编辑卡片。
- 点击已点亮区域仅打开编辑卡片；取消点亮只通过卡片内独立按钮，并提供撤销。
- 编辑卡片支持可选年、年月或年月日，以及最多 500 个 Unicode code point 的纯文本备注。
- 面积极小的区域扩大透明命中范围，但视觉几何不变。

### 搜索与命名

- 全局轻量索引和国家边界包共享稳定 `areaId`，不再用坐标猜测多边形。
- 中文常用名优先，原名辅助，中文、原名和常见别名均可搜索。
- 同名结果展示国家和行政层级。
- 城市搜索结果被选中后，自动加载国家包、进入国家地图并聚焦对应区域。

## 数据架构

### 静态分包

- 构建阶段将可信行政边界源清洗、简化并按 ISO 3166-1 alpha-2 国家代码拆分为 TopoJSON。
- 生产路径为同源 `/travel-footprint-map/data/countries/{ISO}.topojson`。
- `manifest.json` 记录每国行政口径、版本、区域数量、字节数、SHA-256 和更新时间。
- 浏览器首次进入国家时下载对应包，校验后原子写入 IndexedDB；后续可离线访问。
- 公共 Nominatim/Overpass 不再处于主流程，也不提供坐标手工兜底。

### 核心类型

```ts
type AreaId = `${string}:${string}:${string}`;

interface CountryManifestEntry {
  countryCode: string;
  boundaryVersion: string;
  administrativeScheme: string;
  featureCount: number;
  byteSize: number;
  checksum: string;
  updatedAt: string;
}

interface CityAreaProperties {
  areaId: AreaId;
  countryCode: string;
  sourceId: string;
  adminLevel: string;
  nameZh?: string;
  nameLocal: string;
  aliases: string[];
  centroid: [number, number];
}

interface VisitV2 {
  areaId: AreaId;
  areaSnapshot: CityAreaProperties;
  createdAt: string;
  updatedAt: string;
  visitedOn?: string;
  datePrecision?: 'year' | 'month' | 'day';
  note?: string;
}
```

`areaId` 由国家、来源类型和来源稳定标识组成；名称与几何更新不改变到访身份。行政区撤并使用显式迁移表，不按名称静默合并。

## 缓存、更新与异常

- 下载前检查 HTTP 状态和 `Content-Length`，下载后限制实际字节数。
- 解析后验证 schema、国家代码、区域数量、字符串长度、坐标范围、几何类型、单区域与总顶点数。
- 校验和或结构失败时拒绝写入，保留上一有效版本。
- 网络失败且有缓存时继续使用缓存，并标明版本可能过期。
- 网络失败且无缓存时显示国家轮廓、错误分类和重试按钮，不显示伪造区域。
- 用户可查看、更新或删除各国离线包；删除包不删除到访记录。
- IndexedDB 配额失败时保留旧事务状态并提示导出备份，不误报保存成功。

## 存储与迁移

- IndexedDB 升级为 v2，包含 `visitsV2`、`countryPackages`、`meta` 和 `legacyVisits`。
- v1 城市点通过坐标点落面匹配到新区域。
- 唯一命中自动迁移；多个旧点映射同一区域时合并日期并保留带城市名标记的备注；无法唯一命中则进入待确认列表。
- 迁移不能静默删除任何旧记录，且在单事务内提交。
- 统计按 `areaId` 去重，计算区域数、国家数和大洲数。

## 备份与海报

- `BackupV2` 保存标题、V2 到访记录、名称快照、完整到访区域边界和迁移待确认项。
- 用户可选择把已缓存的完整国家包一并加入备份，以便另一设备离线恢复。
- 导入先完整验证并预览记录数、国家数与体积，再选择合并或替换；失败时原子回滚。
- 旧版 `BackupV1` 进入同一迁移流程。
- 海报保留横版 1600×1000 和方形 1200×1200。
- 世界海报展示到访国家与全局统计；国家海报展示全部行政边界并用珊瑚橙填充到访区域。
- 海报不输出私人备注或编辑控件。

## 响应式与可访问性

- 桌面使用地图与可收起手账侧栏；手机使用全屏地图和底部抽屉。
- 国家层保留返回世界、当前国家名称和缩放控件。
- 城市区域可通过指针和键盘选择，具有可见焦点与中文无障碍名称。
- 尊重 `prefers-reduced-motion`；加载、失败、缓存过期和保存失败使用可感知状态文本。

## 性能与兼容约束

- 主应用仍可由单 HTML 启动，但国家边界包是按需联网静态资源，不承诺全球边界全部包含在 HTML 内。
- 最近使用的国家包可离线使用；首次打开新国家需要网络。
- 单国包按大小预算简化几何；简化只能改变绘制顶点，不能改变 `areaId`。
- 支持当前 Chromium、Firefox、Safari；依赖 IndexedDB、SVG、Fetch、AbortController 与 SubtleCrypto。
- 不使用或占用 `127.0.0.1:8080`；未部署自测使用其他空闲端口。

## 验收标准

1. 世界地图点击国家能够进入正确国家层。
2. 国家层展示映射表规定的全部行政区域边界，点击区域立即点亮。
3. 再次点击已点亮区域只打开编辑卡片，取消操作独立且可撤销。
4. 城市搜索能定位同一 `areaId` 的真实边界。
5. 首次加载、缓存命中、过期缓存、断网、404、校验失败和配额失败均有确定行为。
6. v1 本地数据及备份无静默丢失地迁移或进入待确认队列。
7. 合并/替换导入、完整边界备份和两类海报通过测试。
8. 桌面与 360px 手机视口完成两轮浏览器 E2E。
9. 单元测试、类型检查、lint、构建与发布审计全部通过后，才替换线上版本。

## 实施依赖与并行边界

- 强耦合顺序：稳定区域类型与国家口径 → 包验证器 → IndexedDB v2 与迁移 → 应用 UI 集成 → E2E 与部署。
- 可并行任务：边界构建器与纯迁移几何可在共享类型确定后并行；地图渲染引擎与备份 V2 可在区域类型、验证器接口确定后并行；数据文档与海报纯渲染可在各自输入接口确定后并行。
- 不允许并行修改 `src/domain/types.ts`、`src/storage/trip-store.ts`、`src/ui/app.ts` 或发布配置；这些强耦合文件按计划串行集成。
- 每个任务必须独立完成失败测试、实现、自审、定向测试和提交，未闭环缺陷不得传递给下游任务。
