# 全球旅行足迹地图设计规格

## 产品范围

构建一张全球二维旅行地图。用户可离线搜索约 18.5 万城市/市镇，或点击地图从附近候选中选择已经到访的城市。点亮后首次联网获取真实城市行政边界并缓存；无法获得边界时显示珊瑚橙光点。

每个城市只保存一条记录，可选填年、年月或年月日以及 500 字以内纯文本备注。首页展示城市、国家/地区及大洲数量。浏览器自动本地保存，并支持包含缓存边界的版本化 JSON 合并/替换导入导出。地图可导出横版和方形 PNG 海报。

## 体验与视觉

- 简体中文界面，城市中文常用名优先并附原名；中文、英文和当地名称均可搜索。
- 清新旅行手账视觉；低饱和蓝灰海洋、纸张底色、墨水线条和统一珊瑚橙水彩足迹。
- 桌面为地图加可收起侧栏；手机为全屏地图加底部手账抽屉。
- 底图仅显示国家边界和少量国名。支持键盘、可见焦点和减少动态效果。
- 默认标题“我的世界足迹”，允许自定义并用于导出海报。

## 技术架构

- TypeScript + Vite + Vitest + Playwright；开发源码模块化，最终生成一个自包含 HTML。
- Natural Earth 公版数据提供 SVG 世界底图；Mercator 投影负责平移、缩放和点击反投影。
- GeoNames `cities500`（CC BY 4.0）经构建脚本裁剪成紧凑城市索引，搜索与近邻查询在 Web Worker 中执行。
- IndexedDB 保存访问记录和边界，localStorage 保存轻量偏好。
- `BoundaryProvider` 隔离第三方边界服务。公共 Nominatim 仅作为个人低频兜底，限制为每秒一次、永久缓存、8 秒超时并展示署名；正式生产可替换为代理或商业提供方。
- 外部 JSON 和 GeoJSON 一律视为不可信输入，执行 schema、大小、坐标、几何类型、顶点数和字符串长度校验。

## 核心行为

1. 搜索优先级为中文名、原名、ASCII 名、别名；同名项显示国家和一级行政区。
2. 地图点击反投影后返回最近 5 个城市，由用户确认；手机需先进入添加模式。
3. 确认城市后立即保存并显示光点，边界获取在后台执行；成功后切换为区域填色，失败可手动重试。
4. JSON 合并以 `cityId` 去重、`updatedAt` 较新者胜出；替换须二次确认且在完整校验后原子执行。
5. IndexedDB 不可用或配额满时降级到会话内存，并要求用户导出备份，不误报持久化成功。
6. 横版与方形 PNG 使用内嵌 SVG 生成，不包含编辑控件和私人备注。

## 完成标准

- 单元测试覆盖搜索、近邻、投影、日期、统计、导入冲突、边界校验和海报布局。
- 两轮 E2E 分别覆盖完整正向流程和离线、429、超时、恶意输入、窄屏、键盘等异常/边界流程。
- 生产构建、静态检查和全部测试通过；单 HTML 可从 `file://` 与 GitHub Pages 打开。
- GitHub Pages 完成部署并通过线上冒烟检查。
