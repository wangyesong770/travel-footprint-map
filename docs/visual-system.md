# 旅行手账视觉系统

## 设计立场

这不是数据仪表盘，而是一页会随旅行慢慢上色的世界手账。地图是首屏主角；所有控件退到纸张边缘，只有已到访城市使用高饱和颜色。

## 色彩令牌

- `paper #F7F3EA`：页面纸张，不使用纯白。
- `ocean #DDEBE7`：海玻璃色底图，承担最大面积。
- `ink #284743`：松墨绿正文、边界和交互轮廓。
- `coral #E46F61`：仅用于已到访城市、主操作和成功反馈。
- `stamp #D1A34A`：统计邮戳及次要强调。
- `mist #82958F`：辅助文字和未激活边界。

珊瑚色不得用于普通装饰，确保“亮起”始终只有一个语义。

## 字体角色

- 标题：`STKaiti, KaiTi, FZKai-Z03, serif`，只用于地图标题和空状态短句。
- 正文：`ui-rounded, PingFang SC, Microsoft YaHei, sans-serif`。
- 数据：`ui-monospace, SFMono-Regular, Menlo, monospace`，用于统计数字和年份。

不加载网络字体，保证单文件离线和 PNG 导出稳定。

## 标志性元素

一根松墨绿手绘虚线“航线”从统计邮戳绕入地图，再连接到当前选中的城市。它编码真实状态：只有选中城市时才完整连接；空状态仅露出半截线头，引导用户去搜索。其余装饰保持克制。

## 动效与可访问性

- 点亮使用一次 420ms 水彩扩散；地图移动不使用弹簧效果。
- `prefers-reduced-motion` 下取消扩散与平滑移动。
- 所有焦点使用 3px 邮票黄外环；点击目标不小于 44px。
- 状态不能只靠颜色表达；边界填色同时配合纹理/描边，错误和缓存状态有文字。

## 反模板自审

初稿的暖米白＋珊瑚组合过于接近常见生活方式模板。修订后把海玻璃青作为最大色域、松墨绿作为结构色，珊瑚只承担到访语义；没有使用卡片网格、渐变大数字或无意义贴纸。手绘航线承担唯一记忆点，符合旅行路径本身而非泛化装饰。
